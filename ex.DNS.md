## 🧠 Questões Teóricas sobre DNS

**1.**## 🧠 Questões Teóricas sobre DNS

**1.** O que significa a sigla DNS e qual é sua principal função?
A sigla DNS significa Domain Name System (Sistema de Nomes de Domínio). 
**2.** Por que o DNS foi criado? Qual problema ele resolveu na Internet?
O DNS (Domain Name System - Sistema de Nomes de Domínio) foi criado na década de 1980 (oficializado em 1983/1984) para resolver o problema de escalabilidade e memorização da rede de computadores,
que na época era pequena, mas crescia rapidamente. Ele atua como uma "agenda de contatos" da internet, traduzindo nomes de domínio fáceis de lembrar (como exemplo.com) em endereços IP numéricos que os computadores usam para se comunicar (192.0.2.1
**3.** O que é um nome de domínio? Dê um exemplo.
Um nome de domínio é o endereço exclusivo e amigável que as pessoas digitam no navegador para acessar um site na internet. Ele funciona como um substituto fácil de lembrar para o endereço IP (uma longa sequência de números) que os computadores realmente usam para localizar sites. 
Exemplo: No endereço www.google.com, o nome de domínio é google.com. 
**4.** Qual é a função de um servidor DNS?
A principal função de um servidor DNS é traduzir nomes de domínio compreensíveis por humanos (ex: google.com)
em endereços IP numéricos (ex: 192.0.2.1) que computadores usam para identificar e localizar sites na internet. Funciona como uma "lista telefônica" da web, permitindo navegação sem decorar números complexos. 
**5.** Cite dois tipos de registros DNS e explique brevemente um deles.
Registro A (Address): Este registro é o mais fundamental e mapeia diretamente um nome 
de domínio (como exemplo.com) para o endereço IPv4 físico do servidor onde o site está hospedado. É através dele que o navegador descobre o endereço IP correto para acessar o site.
Registro CNAME (Canonical Name): Este registro funciona como um "alias" ou apelido, apontando um subdomínio (ex: blog.exemplo.com) para outro nome de domínio autoritativo, ao invés de um endereço IP.
É útil para gerenciar vários serviços (como ftp, blog, mail) apontando-os para um único servidor principal.
